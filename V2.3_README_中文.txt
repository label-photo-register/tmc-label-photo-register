Label Photo Register V2.3 — QR Code 优先识别修正版

本版重点：
1. 拍摄标签照片后，先从 QR Code 读取完整 Label No.、Lot No.、Part No.、Net (KG)。
   例如包含字母、数字和连字符的完整 Lot 不再只依赖 OCR。
2. Description / Spec 改为识别各自的文字行；优先采用高置信度的结果。
3. 找不到可核实的 QR 数据时继续使用 OCR，并提示你核对 Lot。
4. 保留中文 / English / Bahasa Melayu、每组 2–3 张照片、Excel 小照片与资料同一行、Excel 分享工具、导出确认后清理记录和 ZIP 备份。

更新方法：
- 先用旧版“照片 + 资料 ZIP 备份”保存一次。
- 将本 ZIP 解压后的文件上传到原来的 GitHub Repository，替换旧文件，不需要新建仓库。
- 手机重新打开网页，核对页面显示 V2.3。
- 对已保存的旧标签，打开该标签，点击“重新识别”，检查后保存。

重要说明：
- 本 ZIP 不包含任何真实公司标签照片，也不上传真实标签到 GitHub。
- 浏览器在本机处理照片；联网首次加载 OCR/QR/Excel 软件库。
- 本版已经通过程序语法、二维码资料解析与样本区域测试；真实 Android 手机上的完整操作仍需实测。
- 标签 QR 码若不含这些字段或无法辨认，OCR 仍可能出错。Description / Spec 在污渍或反光情况下必须人工核对。

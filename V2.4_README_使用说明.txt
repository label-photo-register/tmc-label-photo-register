Label Photo Register V2.4 — 精准框选 OCR

1. 正常拍标签并自动识别；二维码支持时优先读取 Label / Lot / Part / Net。
2. 如 Description / Spec 错误，点击「框选品名 / 规格，精准识别」。
3. 选「品名」或「规格」，在放大标签照片上用手指圈住该字段的实际文字（可同时圈两行），不要包含左侧印刷栏名、分隔横线和其他栏位。
4. 点击「重新识别框选区域」，系统将使用两种图像处理方法分别识别。
5. 对照裁切照片检查文字，可直接修改结果，再按「确认并填入字段」。
6. 完成两个字段后请回到表单检查并「保存这一组」。

重要：这不是云端 OCR。识别在本机浏览器进行，图片不会上传服务器；仍可能误识别，特别是污损字母和化学式。需要人工核对。

保留 V2.3 的三语切换、照片 2–3 张、Excel 共享及导出清理功能。旧本机记录保留。上线前先 ZIP 备份，上传所有 V2.4 文件到原来的 GitHub Pages 仓库。GitHub 公共仓库里不可上传真实公司标签照片。

注意：V2.4 是可供测试的精准框选流程，需要在你的 Android 手机浏览器做实际验证。
